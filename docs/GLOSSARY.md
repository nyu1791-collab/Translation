# 固有名詞の用語集

人名、配信者名、ゲーム内の用語など、字幕で使いたい表記をJSONにまとめられます。

```json
{
  "Aurora": "オーロラ",
  "Photon Rush": "フォトンラッシュ"
}
```

PC上の用語集を指定します。

```powershell
translation-video C:/work/source.mp4 --output C:/work/translated --project YOUR_PROJECT --glossary C:/work/private-terms.json
```

`--config` のJSONへ `"glossary": {"Aurora": "オーロラ"}` のように直接書くこともできます。`--glossary` を指定した場合はファイルの内容を使います。空欄の項目は省きます。

用語集は既存の翻訳要求へ同梱します。用語確認のための追加モデル要求や、出力を見て再翻訳するループはありません。文字起こし・発話時刻・話者ラベルは変更せず、訳文で使う表記の希望としてモデルへ渡します。文脈に存在しない用語を挿入する指示にはしません。表記の完全一致を停止条件にする検査も追加していません。

空の用語集では従来と同じ要求・保存キーを使用します。既存の制作をそのまま再利用できます。用語集を追加・変更した場合は翻訳の依頼内容が変わるため、別の出力フォルダで制作してください。文字起こしを別経路へ切り替えることはありません。

生成記録 `manifest.json` の `glossary_terms` に使用した用語数を記録します。用語の内容そのものを使用量ログへ追加しません。人名などの個人用データはPC上のファイルとして保管してください。
