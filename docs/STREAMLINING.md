# 制作経路の整理

## Translation の変更

音声区間ごとの翻訳完了結果を保存し、同じ出力先での再開は完了区間の音声変換・文字起こし・翻訳を省略します。追加の音声空白調査は既定で無効にし、指定されたときだけ行います。発話時刻・話者情報は従来どおり元データを引き継ぎます。

## 共通の動作方針

- 尺、本数、字幕文字数、演出数は目標。目標不足による停止、除外、水増し、追加モデルでの自動やり直しを行いません。
- 品質監査、完成動画の全デコード検査、追加モデル査読を制作経路へ追加しません。
- 本体の制作失敗と、任意のドラフト・装飾の不足を区別して記録します。取得済み動画・字幕・成功済み応答を保持します。
- 既存Runの監視・回収と、新しいモデル要求を分けます。成否不明の制作要求を自動再送しません。
- 認証・通信の失敗、素材不存在、依頼・保存先の取り違えは実行上の問題として表示します。秘密情報の非公開保存と、字幕の元時刻は維持します。

## 役割

| リポジトリ | 担当 |
|---|---|
| ClipForge | 素材取得、話題選定、Transcribe、整文、描画、非公開保存・回収 |
| shorts-only | ショート制作の入口、配信者プリセット、CapCutドラフト |
| ClipForge-Delivery | 案件、完成動画・字幕・タイトル、費用、納品記録 |
| Translation | 海外動画の文字起こし・翻訳・字幕と字幕付き動画 |

## 接続

shorts-onlyとDeliveryは同じ `CLIPFORGE_DIR` を使用できます。既定の `.venv` 以外を使う場合だけ `CLIPFORGE_PYTHON` にPython実行ファイルの絶対パスを指定します。別の認証経路への暗黙切替はしません。

```powershell
$env:CLIPFORGE_DIR = 'C:/work/ClipForge'
$env:CLIPFORGE_PYTHON = 'C:/work/ClipForge/.venv/Scripts/python.exe'
```

Translationの認証は既存のVertex設定を使用します。Antigravity SDKの未確認のTranscribe置換や、新しい認証方式への移行は今回行っていません。

## 今回の作業範囲

コードと設定の読み直し・整理、Python構文の確認を実施。本番API、GPU制作、品質監査、追加テストスイートは実行していません。Windows実機とCapCut最新版の動作実績を追加したものではありません。

## 再開・完了処理の追加整理

文字起こし・翻訳の設定と、字幕表示・動画出力の設定を分離。文字サイズ・行幅・画面サイズ・字幕のみ出力の切替では、完了した翻訳結果を再利用します。旧形式の同一設定による再開にも対応します。

この追加変更では、外部モデルを呼ばないコード動作テストも実施しました。制作中に追加される品質監査ではありません。
