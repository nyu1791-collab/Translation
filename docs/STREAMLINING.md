# Translation単独での制作と再利用

Translationは他の制作リポジトリのソース、Python環境、DBを必要としません。素材取得などの補助コードは自分の `translation._media` に同梱しています。Google Cloudの接続と出力先も、このアプリの設定を使います。

- 音声区間ごとの翻訳完了結果と成功API応答を保存。
- 同じ依頼の再開では完了した音声変換・文字起こし・翻訳を省略。
- 字幕サイズ・行幅・画面サイズ・字幕のみ出力の変更では翻訳を呼び直さず出力だけ更新。
- 追加の音声空白調査は既定で無効。必要な場合だけ指定。
- 原単語時刻・話者を保存し、未翻訳の本文を推測や別モデルで埋めない。
- 用語集は既存の翻訳要求に同梱し、追加の表記確認モデルや再生成ループを増やさない。
- 保存済み翻訳からのSRT・ASS・VTT・対訳表の出力は認証不要、API要求0件。

品質監査、完成映像の全デコード検査、strict品質ゲートを追加しません。字幕の長さや分量は目安であり、不足による停止や水増しをしません。素材不存在や認証・通信の実際の失敗は記録します。

本番APIや有料モデルを使う動作は今回実行していません。字幕書き出しのサンプルを作成し、検査スクリプトや監査工程は追加していません。
